# GPTプロンプトのテスト

`docs/gpt/system-prompt.md` の返信生成を、Claude Codeのサブエージェントで再現テストする。
ChatGPT(マイGPT)に貼らなくても、プロンプト変更の影響をここで確認できる。

## 使い方

Claude Codeで以下を実行する:

```
/gpt-test docs/gpt/test/samples/01-リアセット-既存フィルム-日程おまかせ.md
```

引数を省略すると `samples/` の全サンプルを順に実行する。
モデルは既定で Sonnet(`/gpt-test <ファイル> haiku` で軽量モデルに変更可)。

仕組み: サブエージェントに「system-prompt.md 全文 + 本番APIのcurl手順 + サンプル問い合わせ」を渡し、
実際にAPIを呼ばせて返信文を生成させる。予約作成(POST)は呼ばせない。

## サンプルの追加ルール

- `samples/` に1問い合わせ=1ファイル(.md)で追加する
- **このリポジトリはpublicなので、実名・電話番号は必ず匿名化する**
  (例: 山田太郎 / 090-0000-0000)
- お客様の書き方の癖(「［例］」の残置、誤字、表記揺れなど)はテスト対象なので、
  匿名化以外はできるだけ原文のまま残す

## 注意

- 空き状況は本番のGoogleカレンダーを参照するため、実行日によって結果が変わる
- 料金は本番のGoogle Sheetsを参照する。車種が見つからない場合は
  シート側の表記(誤記含む)も疑うこと
